# 世界史ラボ

**歴史総合・世界史探究**の授業で使える、**年代のツマミを動かすと、地図の王朝や人物が変わる**世界史の学習アプリです。
`index.html` をブラウザ（Chrome / Edge / Safari）で開くだけで動きます（インストール不要）。
地図のデータと部品（d3・topojson）は `vendor/` フォルダに入っているので、**インターネットがなくても動きます**（見出しのフォントだけはネットから読み込みます）。

**公開ページ（GitHub Pages を有効にした場合）**: https://nakatadaiki1012-design.github.io/world-history/

> GitHub Pages の有効にし方：GitHub のこのリポジトリ → Settings → Pages → 「Branch」で公開したいブランチと `/ (root)` を選んで Save。数分後に上のURLで開けます。

## 画面の構成

画面上は **地図と年表／挑戦／授業モード** の3つ（地理ラボ・生物ラボと同じ考え方）。

| モード | 中身 |
|---|---|
| 地図と年表 | 🗺 歴史地図（年代のツマミ）・年表・人物図鑑 |
| 挑戦 | クイズ（地図の国・王朝、都、同じ時代、出来事の順番、人物あて、授業の確認問題） |
| 授業モード | 歴史総合・世界史探究（学習指導要領の項目の順に） |

## 🗺 歴史地図（いちばんの目玉）

- 下の**ツマミ**を左右に動かすと年が変わり、その年の**国・王朝の範囲**（色の面）、**都**（■）、**人物**（●）、**出来事**（◆）が地図に出ます。
  - 例：ツマミを 600 → 750 → 900 と動かすと、隋 → 唐 → 五代十国、ウマイヤ朝 → アッバース朝、フランク王国の変化が見られます。
- **▶**で年が自動で進みます（速さ ×1・×2・×4）。古い時代はツマミの目盛りが粗く、新しい時代ほどこまかくなっています。
- 右はしの年をおすと、年を入力できます（例：`前221`、`1453`）。
- 「前2500」「750」「1914」などのボタンで、教科書によく出る年へとべます。
- 左下のボタンで**見る範囲**（世界・東アジア・内陸アジア・南アジア・東南アジア・西アジア・地中海・ヨーロッパ・アフリカ・アメリカ・大西洋世界）を切りかえ。ホイールや指２本で拡大できます。
- **国・王朝をおす**と、右に説明（期間・都・重要語句・関係する人物・この時代の出来事）。「範囲のうつりかわり」で最大版図などの時期へとべます。
- **人物をおす**と、その人の**一生の足あと**が点線で地図に出ます。「▶ 一生をたどる」で、生まれてから亡くなるまでを地図で追えます（イブン=バットゥータ、玄奘、鄭和、ナポレオンなど）。
- 「現在の国境」をつけると、今の国境を点線で重ねて見られます。
- アドレス（URL）に、今の年・範囲・えらんだものが入ります（例：`#map/750/eastasia/s:tang`）。コピーして送れば同じ場面を開けます。

> 国・王朝の範囲は、教科書の地図をもとにした**おおよその範囲**です。陸地で切り抜いて表示しています。

## ▶ できごとを追う（物語）・なぜ起きた？

- 1つのできごと（三十年戦争・フランス革命など36本）を、地図を動かしながら場面ごとに追います。パリ市内のような町の大きさまで拡大する場面もあります。
- 説明は地図の下に**テロップ**で出ます（スクロール不要）。◀ ❚❚ ▶▶ で操作、▾ でテロップを小さく。
- **🔈 読み上げ**をおすと、場面の説明を日本語の音声で読み上げ、読みおわると次の場面へ進みます（ブラウザの読み上げ機能を使います）。授業や国・人物・出来事の説明にも「🔊 読み上げ」ボタンがあります。
- 出来事をえらぶと「なぜ起きた？（背景・原因・きっかけ）」と「その結果」が出ます。「▶ 原因をさかのぼって地図でたどる」で、原因の流れを地図で順に再生します。
- 右上の ⚙ で、地図に出すもの（都・人物・出来事・勢力圏・現在の国境）や再生の速さを変えられます。

## 人口と経済

年のツマミを動かすと、国ごとの**人口・GDP（経済規模）・1人あたりGDP・世界に占める割合**が、地図（円の大きさ・色の濃さ）とグラフで変わります。
- 地図や順位の国をおすと、折れ線グラフに足せます（対数目盛りの切りかえあり）。
- 「世界に占める割合」では、地域別の積み上げグラフで、19世紀に西ヨーロッパ・アメリカが中国・インドを追いこす「大分岐」と、20世紀後半のアジアの回復が見られます。
- データ：Maddison Project Database 2020（Bolt & van Zanden, 2020、CC BY 4.0、Our World in Data 経由）。今の国の範囲で数えた推計。1820年より前は記録のある年のあいだをつないだ値。ソ連・チェコスロヴァキア・ユーゴスラヴィアは、解体までは全体で、そのあとは後継の国で数えています。

## 年表

地域ごとに、国・王朝の続いた期間を帯で並べます（音楽史年表と同じ考え方）。赤い線が今の年。帯をおすと説明と「🗺 地図で見る」。「● 人物の一生」で人物の帯も重ねられます。

## 人物図鑑

地域・科目・ことばでしぼりこみ。カードをおすと、その人がいた場所と年の地図が開きます。

## 授業モード

- **歴史総合**：A 歴史の扉 ／ B 近代化と私たち ／ C 国際秩序の変化や大衆化と私たち ／ D グローバル化と私たち
- **世界史探究**：A 世界史へのまなざし ／ B 諸地域の歴史的特質の形成 ／ C 諸地域の交流・再編 ／ D 諸地域の結合・変容 ／ E 地球世界の課題

1回の授業は「問い → 説明 → 重要語句 → 考えよう → 確認問題（3問）」。**右側に年代のツマミつきの地図**があり、「🗺 1914年のアフリカ」などのボタンでその場面に切りかわります。確認問題に答えると一覧に ✓ がつきます（記録はそのブラウザの中だけに保存）。

## ファイルの構成

| ファイル | 中身 |
|---|---|
| `index.html` | 画面の骨組みと見た目（CSS） |
| `js/geo.js` | 地図の計算（見る範囲・その年の国の形） |
| `js/histmap.js` | 年代のツマミつきの地図（どの画面でも使う部品） |
| `js/tool-*.js` | 各画面（地図・年表・人物図鑑・クイズ・授業） |
| `js/data/polities-*.js` | 国・王朝の範囲（アジア／西アジア・ヨーロッパ・アフリカ・アメリカ／近現代） |
| `js/data/people.js` `events.js` | 人物と足あと、出来事 |
| `js/data/lessons-*.js` | 授業（歴史総合・世界史探究） |
| `docs/DATA_SPEC.md` | データの書き方（国・人物・出来事・授業を足すとき） |
| `tools/` | 開発用（地図の形のプレビュー画像・画面の写真） |

データを足したり直したりするときは `docs/DATA_SPEC.md` を見てください。たとえば人物の `places` に「何年から何年まで、どこにいたか」を書くと、地図に点と足あとが出ます。
