# 世界史ラボ データの書き方（DATA_SPEC）

アプリは `index.html` を開くだけで動く静的サイト。データはすべて `js/data/*.js` に、
グローバル変数へ「足し込む」形で書く（ファイルをいくつに分けても動くように）。

```js
window.POLITIES = (window.POLITIES || []).concat([ ... ]);
window.PEOPLE   = (window.PEOPLE   || []).concat([ ... ]);
window.EVENTS   = (window.EVENTS   || []).concat([ ... ]);
window.LESSONS  = (window.LESSONS  || []).concat([ ... ]);
```

## 共通ルール

- 年は整数。**紀元前はマイナス**（前221年 → `-221`）。0年は使わない。
- 経度・緯度は `[経度, 緯度]` の順（例：長安 `[108.94, 34.26]`）。東経・北緯がプラス。
- 文章は高校生向けのやさしい日本語。教科書（山川『詳説世界史』・東京書籍『世界史探究』・『歴史総合』）の用語・表記に合わせる。
  例：「アッバース朝」「ムガル帝国」「ササン朝」「カール大帝」「チンギス=カン」「ムハンマド」。
- 史実はふつう教科書にのっている年・事柄だけを使う。あやしいものは書かない。
- `region`（地域）は次のどれか：
  - `east` 東アジア（中国・朝鮮・日本）
  - `inner` 内陸アジア（遊牧国家・中央アジア）
  - `south` 南アジア
  - `sea` 東南アジア
  - `west` 西アジア・北アフリカ（オリエント・イラン・イスラーム世界）
  - `europe` ヨーロッパ（ギリシア・ローマ・ビザンツ・ロシアもここ）
  - `africa` サハラ以南のアフリカ
  - `america` 南北アメリカ
  - `oceania` オセアニア
- `tags`：`'sogo'`（歴史総合で扱う）`'tankyu'`（世界史探究で扱う）。両方なら両方。

## 1. 国・王朝（POLITIES）

```js
{
  id: 'tang',                 // 英小文字・数字・ハイフン。全体で重ならないこと
  name: '唐',                  // 地図に出る名前（短く）
  full: '唐（とう）',          // くわしい名前（任意）
  region: 'east',
  start: 618, end: 907,        // 存続した年
  capital: { name: '長安', lon: 108.94, lat: 34.26 },   // 任意。時代で変わるなら capitals を使う
  capitals: [ { from: 618, to: 907, name: '長安', lon: 108.94, lat: 34.26 } ],  // 任意
  color: '#c0392b',            // 下の「色」を参照
  shapes: [                    // 時代ごとの範囲（from〜to の年のあいだ、その形を表示）
    { from: 618, to: 750, rings: [ [[lon,lat], [lon,lat], ...] ] },
    { from: 751, to: 907, rings: [ [[lon,lat], ...] ] }
  ],
  label: [105, 35],            // 任意。地図上の名前の位置（ないときは形の中心）
  rank: 1,                     // 1=大帝国・教科書の主役 2=ふつう 3=小さい国（ズームしたときだけ名前を出す）
  text: '2〜3文の説明（何をした王朝か。都・建国者・制度・滅亡など）',
  keys: ['律令', '均田制', '租調庸制', '府兵制', '安史の乱'],   // 重要語句 3〜6個
  tags: ['tankyu']
}
```

### 形（shapes）の描き方

- `rings` は「輪」の配列。1つの輪は `[経度, 緯度]` の点を **12〜40 点**、外周に沿って順に並べる（最後の点は最初と同じでなくてよい）。
  飛び地（島など）があるときは輪を増やす。
- **陸地で切り抜いて表示する**ので、海に面した側は海の上を大ざっぱに通してよい（海岸線をなぞらなくてよい）。
  ただし、支配していない別の陸地（例：中国の王朝なのに台湾・朝鮮半島・日本列島）にかからないように注意。
- 内陸の境目（ほかの国とのさかい）は、教科書の地図に合う程度（だいたい 1〜2 度の精度）で。
- 点の回る向き（時計回り・反時計回り）は気にしなくてよい（アプリが直す）。
- 同じ王朝でも最大版図の時期と、衰えた時期で形が大きく変わるなら、shapes を 2〜4 個に分ける。
  shapes の from〜to のすき間・重なりは作らない（最初の from は start、最後の to は end）。
- **現代の国境と同じ範囲**でよい国（おもに 20 世紀以降）は、`rings` のかわりに
  `iso: ['156']` のように**国番号（ISO 3166 数字）**で書ける。複数国の合計なら `iso: ['643','398', ...]`。
  使える番号は世界地図データにあるもの（例：中国156・台湾158・日本392・ロシア643・インド356・
  アメリカ840・トルコ792・イラン364・エジプト818・フランス250・ドイツ276・イギリス826 など）。

### 勢力圏（spheres）

直接支配した範囲（shapes）とは別に、**影響がおよんだ範囲**を斜線で表示できる。
例：唐の羈縻政策・冊封の範囲、清の朝貢国・藩部、モンゴル帝国の宗主権、オスマン帝国の宗主権（クリミア=ハン国・北アフリカ）、
列強の中国での勢力範囲（1898〜）、イギリスの非公式帝国、冷戦期の東西陣営（NATO・ワルシャワ条約機構など）。

```js
spheres: [
  { from: 1759, to: 1894, name: '朝貢国・藩属国', kind: 'tribute', rings: [ ... ] },   // または iso: [...]
  { from: 1898, to: 1914, name: '勢力範囲（山東半島）', kind: 'influence', rings: [ ... ] }
]
```

- `kind`：`tribute` 朝貢・冊封／`suzerain` 宗主権・保護国／`influence` 勢力範囲・影響圏／`bloc` 同盟・陣営／`claim` 名目上の領有
- shapes と同じく陸地で切り抜く。shapes と重なってもよい（shapes が上に描かれる）。from〜to は polity の start〜end の中に。
- 名前 `name` は右の説明に出る（例：「冊封を受けた国々（朝鮮・琉球・ベトナム）」）。

### 精度

- 世界地図は 1:50m（Natural Earth）の海岸線を使う。輪の点は **25〜80 点**を目安に、
  川（黄河・長江・淮河・アムダリヤ・ドナウ・ライン・ユーフラテス など）・山脈・砂漠のふち・海峡など、
  **実際に境目になった地形**に沿わせる。同じ年に隣り合う国どうしは、境目の点を**同じ座標**にする（すき間・重なりを作らない）。
- 現代の国境と同じところ（例：19 世紀以降の多くの国境）は、点をその国境に合わせる。

### 色

地域ごとの色の系統（同じ時代に隣り合う国どうしは、明るさや色合いを少しずらして見分けられるように）。

| region | 色の系統 |
|---|---|
| east | 赤・朱・えんじ（`#c0392b` `#d35400` `#a93226` `#e67e22` …）。朝鮮は桃色系、日本は紫系 |
| inner | 茶・黄土（`#a0522d` `#b8860b` `#8d6e63` …） |
| south | 橙・山吹（`#e69b00` `#f39c12` …） |
| sea | 黄緑（`#7cb342` `#9ccc65` …） |
| west | 緑（`#1e8449` `#27ae60` `#16a085` …） |
| europe | 青・藍（`#1f5f8b` `#2e86c1` `#5d6d7e` …）。ビザンツは紫寄り `#6c3483` |
| africa | 黄（`#d4ac0d` …） |
| america | 青緑（`#148f77` …） |

## 2. 人物（PEOPLE）

```js
{
  id: 'li-bai',
  name: '李白',
  kana: 'りはく',
  born: 701, died: 762,          // わからなければ「ごろ」の年でよい（about: true をつける）
  about: false,
  region: 'east',
  role: '詩人',                   // 皇帝・王・思想家・宗教家・軍人・政治家・学者・旅行家・芸術家 など
  polity: 'tang',                 // 関係の深い王朝の id（任意）
  places: [                       // 一生のうち、どこにいたか（年の順・すき間なく）
    { from: 701, to: 724, name: '蜀（四川）', lon: 104.1, lat: 30.7, note: '少年時代' },
    { from: 725, to: 741, name: '長江流域を放浪', lon: 114.3, lat: 30.6 },
    { from: 742, to: 744, name: '長安', lon: 108.94, lat: 34.26, note: '玄宗に仕える' },
    { from: 745, to: 762, name: '各地を放浪・当塗で死去', lon: 118.5, lat: 31.6 }
  ],
  text: '2〜3文の説明（何をした人か）',
  keys: ['唐詩', '杜甫'],
  tags: ['tankyu']
}
```

- 地図の年スライダーが born〜died のあいだにあるとき、その年の `places` の場所に点で出る。
- 旅行家・遠征した人（イブン=バットゥータ、マルコ=ポーロ、アレクサンドロス、玄奘、鄭和、チンギス=カン、ナポレオン など）は
  places を細かく（5〜15 個）書くと、地図に足あとの線が出る。

## 4. 授業（LESSONS）

```js
{
  id: 'sogo-03',
  course: 'sogo',                 // 'sogo' 歴史総合 / 'tankyu' 世界史探究
  unit: 'B 近代化と私たち',        // 学習指導要領の大項目
  sub: '(2) 結び付く世界と日本の開国', // 中項目
  title: '18世紀のアジアの繁栄と交易',
  question: 'この時間の問い（〜のはなぜだろう？）',
  body: [                         // 3〜5 個。1つの p は 120〜250 字
    { h: '見出し', p: '本文' }
  ],
  terms: ['清', '朝貢', '広州', '茶'],    // 重要語句 4〜8 個
  maps: [                         // 「地図で見る」ボタン。1〜3 個
    { label: '1750年のアジア', year: 1750, view: 'eastasia' }
  ],
  think: '考えよう：資料や地図から考える問い（1つ）',
  quiz: [                         // 3 問。c は 4 つ、a は正解の番号（0 から）
    { q: '問題文', c: ['ア', 'イ', 'ウ', 'エ'], a: 2, exp: '解説（1〜2文）' }
  ]
}
```

`view`（地図の見る範囲）は次のどれか：
`world` 世界全体 / `eastasia` 東アジア / `inner` 内陸アジア / `southasia` 南アジア / `seasia` 東南アジア /
`westasia` 西アジア / `med` 地中海 / `europe` ヨーロッパ / `africa` アフリカ / `america` アメリカ / `atlantic` 大西洋世界

## 5. 物語（STORIES）― 1つのできごとを地図で順に追う

```js
window.STORIES = (window.STORIES || []).concat([{
  id: 'thirty-years-war',
  title: '三十年戦争',
  period: '1618〜1648年',
  region: 'europe',
  view: 'europe',                  // 地図の基本の範囲（VIEWS のキー）
  tags: ['tankyu'],
  summary: '全体のまとめ（2〜3文）',
  steps: [                         // 6〜14 個。年の順
    {
      year: 1618, date: '5月23日',  // date は任意（月日・季節など）
      title: 'プラハ窓外投擲事件',
      text: '何が起き、だれが何をしたか（80〜160字）。',
      place: 'プラハ', lon: 14.42, lat: 50.09,
      span: 6,                     // 画面に入れる横の幅（経度で何度ぶん）。国全体 8〜15、地方 2〜5、都市とその周辺 0.3〜1
      people: ['ferdinand-2'],     // 任意。js/data/people.js にある id だけ
      polities: ['hre'],           // 任意。強調する国・王朝の id（polities-*.js にあるもの）
      marks: [                     // 任意。地図に出す地点（★はこの場面の中心、ほかは ●）
        { name: 'ヴァレンシュタイン軍', lon: 12.3, lat: 51.3 }
      ],
      routes: [                    // 任意。軍の進路・移動・航路（矢印つき）
        { name: 'グスタフ=アドルフの進軍', color: '#1f5f8b', pts: [[13.4, 54.1], [13.4, 52.5], [12.4, 51.3]] }
      ],
      lines: [                     // 任意。矢印なしの線（川・前線・城壁など）。都市の場面で地形の手がかりに
        { name: 'セーヌ川', pts: [[2.2, 48.83], [2.35, 48.85], [2.45, 48.82]] }
      ]
    }
  ]
}]);
```

- 都市の場面（パリのバスティーユ・ヴェルサイユなど）は `span: 0.3〜0.8` にし、`lines` で川（セーヌ川など）を、`marks` で場所を示す。
- routes の色：攻める側・動く側の国の色に合わせる。

## 6. 原因と結果（CAUSES）― 「なぜ起きた？」をたどる

出来事どうしを「原因 → 結果」でつなぐ。出来事は `EVENTS` の `title`（完全に同じ文字列）で指す。
EVENTS にない原因が必要なときは、同じファイルで `window.EVENTS` に足してよい（書き方は 3. と同じ）。

```js
window.CAUSES = (window.CAUSES || []).concat([
  { from: '大陸封鎖令', to: 'ロシア遠征', kind: 'trigger', why: 'ロシアが大陸封鎖令を破ってイギリスと貿易を再開したため、ナポレオンは遠征を決めた。' },
  { from: '七年戦争', to: 'アメリカ独立戦争', kind: 'background', why: '…' }
]);
```

- `kind`：`background` 背景・遠因（長い時間かけて条件をつくった）／`cause` 原因／`trigger` きっかけ（直接の引き金）／`result` 結果・影響（from が to をもたらした、と書きにくいときの補助。ふつうは cause でよい）
- `why`：なぜつながるのかを 1〜2 文（40〜100 字）。教科書の説明に合わせる。
- 物語（STORIES）には `causes: ['出来事の title', …]`（その物語の背景・原因）と `results: [...]`（その後への影響）をつけてよい。

## 7. 画像資料（IMAGES）

肖像以外の画像資料（絵画・写真・地図・遺物・史料）。ウィキメディア・コモンズの、自由に使えるもの（Public domain・CC0・CC BY・CC BY-SA）だけ。

```js
window.IMAGES = (window.IMAGES || []).concat([
  { key: 'story:french-revolution:2',   // 物語の場面（id と 1 から数えた場面の番号）／ 'event:<title>' ／ 'polity:<id>' ／ 'person:<id>'
    file: 'Prise_de_la_Bastille.jpg',      // コモンズのファイル名
    what: 'ウエル「バスティーユ襲撃」（1789年）',  // 何の画像か（短い日本語）
    artist: 'Jean-Pierre Houël', license: 'Public domain',
    page: 'https://commons.wikimedia.org/wiki/File:Prise_de_la_Bastille.jpg' }
]);
```

アプリは `https://commons.wikimedia.org/wiki/Special:FilePath/<file>?width=480` で読みこむ（インターネットが必要）。

## 8. 語り口（ていねいに、そしておもしろく）

**です・ます調**で書く（博物館の解説員や、話のうまい先生の講義のイメージ）。くだけた言い方（「〜なんだ」「〜だよ」「〜しちゃった」）は使わない。
おもしろさは言葉づかいではなく、**中身**でつくる：
- 具体的な場面・数字・人物の実際の言葉・意外な事実（「実は」「意外なことに」で始めてよい）。
- 「なぜ？」の問いかけから入り、答えを示す。人物の立場や気持ちを想像させる（「もしあなたが〜だったら」）。
- 現代とのつながり・くらべ（「今の〜にあたります」）。
- **史実はまげない**。逸話・伝説は「〜と伝えられています」「〜という説もあります（確かではありません）」とはっきり書く。
- 差別的な表現・特定の宗教や民族をからかう表現はしない。


## 11. 歴史的な地名（PLACES）

時代によって名前が変わる町・地域。地図には、その年の名前で出し、おすと歴史が出る。

```js
window.PLACES = (window.PLACES || []).concat([{
  id: 'xian',
  lon: 108.94, lat: 34.26,
  region: 'east',
  rank: 1,                         // 1=世界史の超重要都市（世界全体でも出す） 2=重要（地域を見ているとき） 3=拡大したとき
  modern: '西安',                   // 今の名前
  names: [                         // 時代ごとの名前（年の順・すき間があってもよい）。to は今も続くなら 2025
    { from: -1046, to: -771, name: '鎬京', note: '西周の都（今の西安の西）' },
    { from: -202, to: 904, name: '長安', note: '前漢・隋・唐の都' },
    { from: 1369, to: 2025, name: '西安' }
  ],
  text: '町の歴史を 2〜4 文（語り口は 8. を参考に、でも正確に）',
  fun: '任意。豆知識 1 つ（60〜120 字）'
}]);
```

## 12. 物語の種類（STORIES の kind）

物語には `kind` をつける（ないときは 'event'）。一覧で種類ごとにしぼりこめる。
- `event` できごと：1つのできごとを追う（今までの物語）
- `person` 人物：1人の一生を、場所を移りながらたどる。`person: '<people.js の id>'` をつける。生い立ち・転機・業績・晩年・その後への影響まで。人物の性格や決断の理由など「人間」としての深掘りを大切に。
- `theme` テーマ：長い時代をまたいで、1つのテーマの移り変わりを追う（例：中国の土地制度、宗教の成立と広がり、戦い方の変遷）。場面は数百〜数千年にわたってよい。各場面は「その時代のしくみ」と「なぜ変わったか」を説明する。`theme: 'land' | 'religion' | 'war' | 'trade' | 'state' | 'science' | 'society'` をつける。

- `term` 用語：入試・テストに出る1つの用語（法律・制度・土地制度・条約・書物・建物/遺跡・出来事・思想・経済）を、4〜6場面の短い物語で解説する。`term: '<用語集の term>'`、`tcat: '法律・制度' | '土地制度' | '条約・宣言' | '書物' | '建物・遺跡' | '出来事' | '経済・社会' | '思想・宗教'`、`exam: ['テストのポイント（40字以内）', …]`（3つ）をつける。場面は「背景（なぜ生まれた）→ 中身 → 具体の場面 → その後・影響」の順。用語集のその語のページに「▶ 物語で学ぶ」が出る。ファイルは js/data/stories-terms-*.js。

## 13. 読み仮名（YOMI）― 読み上げ用

読み上げ（音声合成）がまちがえやすい漢字の語に、ひらがなの読みをつける。画面には出さない。
```js
window.YOMI = Object.assign(window.YOMI || {}, { '冊封': 'さくほう', '匈奴': 'きょうど', '開封': 'かいほう' });
```
- キーは漢字の語（2字以上）。長い語ほど先に置きかえる（「均田制」は「均田」より先）。
- 人名・王朝名・地名・歴史用語・特別な読み（例：「東京（とうけい）」は宋の都なら別に。文脈で読みが変わる語は入れない）。
- 普通の語（「帝国」「独立」など）は入れない（音声合成が正しく読めるため）。

## 14. 用語集（GLOSSARY）― ウィキのように用語のページへ飛べる・テスト対策

```js
window.GLOSSARY = (window.GLOSSARY || []).concat([{
  term: '均田制', yomi: 'きんでんせい',
  def: '北魏の孝文帝が始め、隋・唐に受けつがれた土地制度。国家が農民に土地を割りあて、税（租調庸）と兵役を負担させた。',   // 60〜140字、である調（教科書・用語集の書き方）
  year: 485, end: 780,           // その語がいちばん関係する年（期間なら end も）。わからなければ省く
  region: 'east',                // REGION のキー
  cat: '制度',                   // 国家・王朝／人物／事件・戦争／条約・宣言／制度・政策／思想・宗教／文化・学問／経済・社会／地名・地域／組織・運動
  rank: 3,                       // 重要度 3＝共通テスト・定期テストで必ず出る、2＝よく出る、1＝知っておくとよい
  course: ['tankyu'],            // 'sogo' 歴史総合 ／ 'tankyu' 世界史探究
  related: ['租調庸制', '府兵制', '両税法']   // 関連する用語（この用語集の term と同じ書き方で）
}]);
```
