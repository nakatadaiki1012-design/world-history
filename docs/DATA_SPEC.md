# 世界史ラボ データの書き方（DATA_SPEC）

アプリは `index.html` を開くだけで動く静的サイト。データはすべて `js/data/*.js` に、
グローバル変数へ「足し込む」形で書く（ファイルをいくつに分けても動くように）。

```js
window.POLITIES = (window.POLITIES || []).concat([ ... ]);
window.PEOPLE   = (window.PEOPLE   || []).concat([ ... ]);
window.EVENTS   = (window.EVENTS   || []).concat([ ... ]);
window.LESSONS  = (window.LESSONS  || []).concat([ ... ]);
```

## 共通ルール

- 年は整数。**紀元前はマイナス**（前221年 → `-221`）。0年は使わない。
- 経度・緯度は `[経度, 緯度]` の順（例：長安 `[108.94, 34.26]`）。東経・北緯がプラス。
- 文章は高校生向けのやさしい日本語。教科書（山川『詳説世界史』・東京書籍『世界史探究』・『歴史総合』）の用語・表記に合わせる。
  例：「アッバース朝」「ムガル帝国」「ササン朝」「カール大帝」「チンギス=カン」「ムハンマド」。
- 史実はふつう教科書にのっている年・事柄だけを使う。あやしいものは書かない。
- `region`（地域）は次のどれか：
  - `east` 東アジア（中国・朝鮮・日本）
  - `inner` 内陸アジア（遊牧国家・中央アジア）
  - `south` 南アジア
  - `sea` 東南アジア
  - `west` 西アジア・北アフリカ（オリエント・イラン・イスラーム世界）
  - `europe` ヨーロッパ（ギリシア・ローマ・ビザンツ・ロシアもここ）
  - `africa` サハラ以南のアフリカ
  - `america` 南北アメリカ
  - `oceania` オセアニア
- `tags`：`'sogo'`（歴史総合で扱う）`'tankyu'`（世界史探究で扱う）。両方なら両方。

## 1. 国・王朝（POLITIES）

```js
{
  id: 'tang',                 // 英小文字・数字・ハイフン。全体で重ならないこと
  name: '唐',                  // 地図に出る名前（短く）
  full: '唐（とう）',          // くわしい名前（任意）
  region: 'east',
  start: 618, end: 907,        // 存続した年
  capital: { name: '長安', lon: 108.94, lat: 34.26 },   // 任意。時代で変わるなら capitals を使う
  capitals: [ { from: 618, to: 907, name: '長安', lon: 108.94, lat: 34.26 } ],  // 任意
  color: '#c0392b',            // 下の「色」を参照
  shapes: [                    // 時代ごとの範囲（from〜to の年のあいだ、その形を表示）
    { from: 618, to: 750, rings: [ [[lon,lat], [lon,lat], ...] ] },
    { from: 751, to: 907, rings: [ [[lon,lat], ...] ] }
  ],
  label: [105, 35],            // 任意。地図上の名前の位置（ないときは形の中心）
  rank: 1,                     // 1=大帝国・教科書の主役 2=ふつう 3=小さい国（ズームしたときだけ名前を出す）
  text: '2〜3文の説明（何をした王朝か。都・建国者・制度・滅亡など）',
  keys: ['律令', '均田制', '租調庸制', '府兵制', '安史の乱'],   // 重要語句 3〜6個
  tags: ['tankyu']
}
```

### 形（shapes）の描き方

- `rings` は「輪」の配列。1つの輪は `[経度, 緯度]` の点を **12〜40 点**、外周に沿って順に並べる（最後の点は最初と同じでなくてよい）。
  飛び地（島など）があるときは輪を増やす。
- **陸地で切り抜いて表示する**ので、海に面した側は海の上を大ざっぱに通してよい（海岸線をなぞらなくてよい）。
  ただし、支配していない別の陸地（例：中国の王朝なのに台湾・朝鮮半島・日本列島）にかからないように注意。
- 内陸の境目（ほかの国とのさかい）は、教科書の地図に合う程度（だいたい 1〜2 度の精度）で。
- 点の回る向き（時計回り・反時計回り）は気にしなくてよい（アプリが直す）。
- 同じ王朝でも最大版図の時期と、衰えた時期で形が大きく変わるなら、shapes を 2〜4 個に分ける。
  shapes の from〜to のすき間・重なりは作らない（最初の from は start、最後の to は end）。
- **現代の国境と同じ範囲**でよい国（おもに 20 世紀以降）は、`rings` のかわりに
  `iso: ['156']` のように**国番号（ISO 3166 数字）**で書ける。複数国の合計なら `iso: ['643','398', ...]`。
  使える番号は世界地図データにあるもの（例：中国156・台湾158・日本392・ロシア643・インド356・
  アメリカ840・トルコ792・イラン364・エジプト818・フランス250・ドイツ276・イギリス826 など）。

### 色

地域ごとの色の系統（同じ時代に隣り合う国どうしは、明るさや色合いを少しずらして見分けられるように）。

| region | 色の系統 |
|---|---|
| east | 赤・朱・えんじ（`#c0392b` `#d35400` `#a93226` `#e67e22` …）。朝鮮は桃色系、日本は紫系 |
| inner | 茶・黄土（`#a0522d` `#b8860b` `#8d6e63` …） |
| south | 橙・山吹（`#e69b00` `#f39c12` …） |
| sea | 黄緑（`#7cb342` `#9ccc65` …） |
| west | 緑（`#1e8449` `#27ae60` `#16a085` …） |
| europe | 青・藍（`#1f5f8b` `#2e86c1` `#5d6d7e` …）。ビザンツは紫寄り `#6c3483` |
| africa | 黄（`#d4ac0d` …） |
| america | 青緑（`#148f77` …） |

## 2. 人物（PEOPLE）

```js
{
  id: 'li-bai',
  name: '李白',
  kana: 'りはく',
  born: 701, died: 762,          // わからなければ「ごろ」の年でよい（about: true をつける）
  about: false,
  region: 'east',
  role: '詩人',                   // 皇帝・王・思想家・宗教家・軍人・政治家・学者・旅行家・芸術家 など
  polity: 'tang',                 // 関係の深い王朝の id（任意）
  places: [                       // 一生のうち、どこにいたか（年の順・すき間なく）
    { from: 701, to: 724, name: '蜀（四川）', lon: 104.1, lat: 30.7, note: '少年時代' },
    { from: 725, to: 741, name: '長江流域を放浪', lon: 114.3, lat: 30.6 },
    { from: 742, to: 744, name: '長安', lon: 108.94, lat: 34.26, note: '玄宗に仕える' },
    { from: 745, to: 762, name: '各地を放浪・当塗で死去', lon: 118.5, lat: 31.6 }
  ],
  text: '2〜3文の説明（何をした人か）',
  keys: ['唐詩', '杜甫'],
  tags: ['tankyu']
}
```

- 地図の年スライダーが born〜died のあいだにあるとき、その年の `places` の場所に点で出る。
- 旅行家・遠征した人（イブン=バットゥータ、マルコ=ポーロ、アレクサンドロス、玄奘、鄭和、チンギス=カン、ナポレオン など）は
  places を細かく（5〜15 個）書くと、地図に足あとの線が出る。

## 3. 出来事（EVENTS）

```js
{
  year: 1206,  end: 1206,         // end は任意（戦争など期間があるとき）
  title: 'チンギス=カン即位',
  place: 'モンゴル高原', lon: 107, lat: 47.5,
  region: 'inner',
  kind: 'politics',               // politics 政治 / war 戦争 / culture 文化・宗教 / economy 経済・交易 / society 社会
  text: '1〜2文の説明',
  tags: ['tankyu']
}
```

## 4. 授業（LESSONS）

```js
{
  id: 'sogo-03',
  course: 'sogo',                 // 'sogo' 歴史総合 / 'tankyu' 世界史探究
  unit: 'B 近代化と私たち',        // 学習指導要領の大項目
  sub: '(2) 結び付く世界と日本の開国', // 中項目
  title: '18世紀のアジアの繁栄と交易',
  question: 'この時間の問い（〜のはなぜだろう？）',
  body: [                         // 3〜5 個。1つの p は 120〜250 字
    { h: '見出し', p: '本文' }
  ],
  terms: ['清', '朝貢', '広州', '茶'],    // 重要語句 4〜8 個
  maps: [                         // 「地図で見る」ボタン。1〜3 個
    { label: '1750年のアジア', year: 1750, view: 'eastasia' }
  ],
  think: '考えよう：資料や地図から考える問い（1つ）',
  quiz: [                         // 3 問。c は 4 つ、a は正解の番号（0 から）
    { q: '問題文', c: ['ア', 'イ', 'ウ', 'エ'], a: 2, exp: '解説（1〜2文）' }
  ]
}
```

`view`（地図の見る範囲）は次のどれか：
`world` 世界全体 / `eastasia` 東アジア / `inner` 内陸アジア / `southasia` 南アジア / `seasia` 東南アジア /
`westasia` 西アジア / `med` 地中海 / `europe` ヨーロッパ / `africa` アフリカ / `america` アメリカ / `atlantic` 大西洋世界
